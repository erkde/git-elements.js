Input methods

Every input resolves to the same thing: uncolored unified diff text. Choose the delivery method that fits where the patch already lives.

Load from a URL

Use src for a browser-accessible patch file.

<git-diff
  src="./changes.patch"
  theme="dark"
></git-diff>

Assign from JavaScript

Use patch when the diff is already in memory.

const diff = document.querySelector("git-diff");

diff.patch = rawDiffText;

Embed plain text

A non-executable text/plain child keeps declarative patches beside their markup. Common HTML indentation is removed. 

<git-diff theme="dark">
  <script type="text/plain">
    --- a/message.txt
    +++ b/message.txt
    @@ -1 +1 @@
    -Hello, world!
    +Hello, Git Elements!
  </script>
</git-diff>

<git-diff> API

The element stays deliberately small, with URL, property, and inline inputs plus native-style loading events.

Name Kind Purpose
src Attribute / property Fetch unified diff text from a URL. Changing it reloads the patch.
patch JavaScript property Set raw unified diff text directly, cancel any pending load, and rerender.
parsedDiffs Read-only property Inspect the parsed files, hunks, line numbers, statuses, and metadata.
theme Attribute Use light or dark; omit it for OS preference.
line-numbers Boolean attribute / property Show the old and new line-number gutters. Hidden by default.
<script type="text/plain"> Child element Provide an inline patch declaratively.
slot="loading" Named slot Optional content shown when a src request takes longer than 150ms.
slot="error" Named slot Optional content shown when a src request fails.
load Event Fires after a src patch has loaded and rendered.
error Event Fires when a src patch cannot be loaded.

Loading lifecycle

While src is loading, the component exposes aria-busy but renders no status UI by default. Supply named slots when the page needs loading or error content. Loading content is delayed by 150ms to avoid flicker on fast requests.

Provide fallback content

The page controls the wording, styling, and complexity of each state.

<git-diff src="./changes.patch">
  <div slot="loading">Loading changes…</div>
  <div slot="error">Changes unavailable.</div>
</git-diff>

Respond to the result

Success and failure also follow the familiar native resource event model.

const diff = document.querySelector("git-diff");

diff.addEventListener("load", () => {
  console.log("Diff loaded");
});

diff.addEventListener("error", () => {
  console.log("Diff failed to load");
});

Styling

Use CSS custom properties for the component palette and typography. For targeted changes inside the shadow tree, use the exposed CSS parts. 

git-diff {
  --git-diff-bg: #171328;
  --git-diff-add-text: #7de2b8;
  --git-diff-del-text: #ff8fa3;
  --git-diff-hunk-text: #b5a4ff;
  --git-diff-font-size: 13px;
  --git-diff-loading-delay: 200ms;
}

git-diff::part(file-header) {
  text-transform: uppercase;
}
